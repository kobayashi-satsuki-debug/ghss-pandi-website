Good to know

Questions people ask

Is the app free?

Yes — no price, no subscription, no ads.

Why is it not on the Play Store?

A paid developer account and a review for every update would slow releases down.

Will it work on an iPhone?

Not yet; use the website in Safari and add it to your home screen.

Is my data safe?

The same database and the same rules as the website.

How do I update it?

Install the newer file over the old one.

For the school office

  1. Build the signed APK as the app repository's README describes.
  2. Create a release and attach the .apk file.
  3. Tag it v1.0.0 or similar; this page then shows the version, size and date by itself.

With no release yet, the buttons lead to the repository and its Releases page.
